How It Works

A quick breakdown of what this tool measures and how it produces a result.

1

Input Factors

The predictor collects five values across two categories:

Cellphone Usage
  • Daily screen time (hrs)
  • Academic app usage (hrs)
  • Social media usage (hrs)
Study Habits
  • Study hours per day
  • Study frequency per week
2

Prediction

These five inputs feed a Linear Regression model that estimates a General Weighted Average (GWA) on the 1.00–5.00 scale.

3

Performance Bands

Your predicted GWA falls into one of four bands:

Excellent 1.00–1.75 Good 1.76–2.50 Satisfactory 2.51–3.00 Failing 3.01–5.00
4

Development Stage

This web prototype currently uses a Linear Regression model trained on synthetic data while we finalize real survey data collection. Once real data is gathered, the system will be retrained — maintaining the same model architecture.
