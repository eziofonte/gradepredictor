How It Works

A quick breakdown of what this tool measures and how it produces a result.

1. Input Factors

The estimator collects two categories of behavior:

  • Cellphone usage — average daily screen time, and cellphone use during study time.
  • Study habits — average study hours per day, and study frequency per week.

2. Prediction

These inputs are used to estimate a General Weighted Average (GWA) on the 1.00–5.00 scale (lower is better), matching the Philippine university grading convention.

3. Performance Bands

BandGWA Range
Excellent1.00 – 1.75
Good1.76 – 2.50
Satisfactory2.51 – 3.00
Failing3.01 – 5.00

4. Development Stage

This web prototype currently uses trained Linear Regression and Decision Tree models on synthetic data while we finalize real survey data collection. Once real data is gathered, the system will be retrained on the real data — maintaining the same model architecture.
