How It Works

A step-by-step breakdown of how this tool estimates academic performance.

1

Input Factors

The estimator collects two categories of behavior:

  • Cellphone Usage
    • Average daily screen time
    • Academic app usage during study time
    • Social media usage during study time
  • Study Habits
    • Average study hours per day
    • Study frequency per week
2

Prediction

These inputs are used to estimate a General Weighted Average (GWA) on the 1.00–5.00 scale (lower is better), matching the Philippine university grading convention.

3

Performance Bands

The predicted GWA is mapped to a performance category based on the following ranges:

  • Excellent: 1.00 – 1.75
  • Good: 1.76 – 2.50
  • Satisfactory: 2.51 – 3.00
  • Failing: 3.01 – 5.00
4

Model Used

This web prototype uses a Linear Regression model trained on synthetic data to make predictions. The Decision Tree model has been removed as per the latest update.
